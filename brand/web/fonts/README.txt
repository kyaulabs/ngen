NGEN 1.4 — supplied Prism typefaces

Copied unchanged from the user-provided kyaulabs/prism-web fonts directory:
Neo Sans Pro and Operator Mono Lig / SSm Lig Nerd Font variants.

The binaries retain their embedded copyright and license notices. The website's
AGPL-3.0 license does not relicense these fonts. Applicable font web-embedding,
redistribution and authoring permissions remain necessary.

The website self-hosts these files. Reference CSS uses the same family names.
SVG presentation labels require the fonts in the authoring environment; use the
supplied PNG/PDF exports where the fonts are unavailable. The optional exporter
uses an isolated Fontconfig configuration and never installs fonts globally.
