# Bounded offline GLB import

Status: **M2-D partial; M2 is not complete.** This tooling-only slice starts from integrated foundation `e1cc4f4`, independently of [shader PR #3](https://github.com/kyaulabs/ngen/pull/3). It returns an owning CPU scene and inspection JSON. It does not write a cooked runtime package, upload resources or render the frigate.

`assetc inspect` admits one embedded static glTF 2.0 GLB with indexed/unindexed triangles, float32 positions/normals/UV0, optional UV1, validated tangents, metallic-roughness materials, texture slots/samplers, bounded PNG decoding, affine node transforms and punctual lights. `KHR_lights_punctual` and `KHR_materials_emissive_strength` are supported; other declared extensions, external/data/network URIs, sparse accessors, vertex colors, animation, skinning and compressed source geometry reject explicitly. The standard library supplies none of the required parsing, image decoding or reference tangent generation; fastgltf 0.9.1, simdjson 4.6.4, libpng 1.6.59, MikkTSpace and meshoptimizer 1.0 are optional offline dependencies. Zlib 1.3.2 is transitive. CPU/renderer locks and runtime linkage remain unchanged. Exact refs/settings and byte-exact notices are retained in `tool-graph.json` and `licenses/`.

The owner approved rebuilding tangents during cooking while retaining the original GLB. Strict inspection still rejects its invalid authored frames. Explicit `--rebuild-tangents` uses per-corner MikkTSpace results and exact meshoptimizer remapping, preserving mirrored seams rather than overwriting shared vertices. Narrow, tested repairs handle float-rounded zero-angle weights and projection of inherited/default axes on UV-degenerate faces. Generated frames must still meet the original validation tolerance; unusable results reject. Positions, normals, UVs and triangle count are preserved; canonicalization can split or merge equivalent vertex records, not simplify the mesh.

Rebuilding admits bounded float32 geometry/UV ranges and at most 4,096 special corner repairs. Duplicate JSON keys, unsafe accessor ranges/strides/counts, invalid indices, nonfinite values, nonunit normals/quaternions, projective/singular transforms, cycles and missing material UV data reject. PNG CRCs are checked; channel bytes are not reinterpreted using PNG gamma metadata. Cancellation is cooperative, not internally interruptible during a library parse, image decode or tangent-generation call. These bounds are not a hard memory/time sandbox or universal out-of-memory recovery guarantee.
