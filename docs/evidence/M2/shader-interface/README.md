# Offline shader interface and native fixture

Status: **Linux M2-C implementation verified; Windows/NVIDIA execution and compiler-choice acceptance pending. M2 is not complete.** Source starts from integrated foundation `e1cc4f4`; this directory records a separate shader slice, not the imported-ship runtime renderer.

The renderer preparation now resolves build-only `slangc/2026.21@ngen/tools`, SPIR-V Tools 1.4.357.0 and matching SPIR-V headers. Both upstream Slang archive digests were verified. The namespaced [recipe](../../../../recipes/slangc/README.md) retains licenses/notices in the tool package. Existing renderer pins and `conan.lock` are unchanged. No compiler or validator library is linked into the simulation or native GPU executable. The retained legal notices are byte-exact; three path-specific whitespace attributes preserve upstream CRLF, trailing spaces or the final blank line. Logs normalize local paths, terminal color and trailing whitespace; `original-log-bytes.sha256` identifies the pre-normalization bytes.

`tools/shaderc/compile.py` compiles the finite PBR vertex/fragment pair and sphere-culling entry offline: Vulkan 1.3, SPIR-V 1.5, column-major CPU matrices, std140 constant buffers and ordinary descriptors. It treats compiler warnings as errors, validates modules, rejects optional capabilities, limits source/artifact sizes to 4 MiB and bounds each child process to 30 seconds. Diagnostic size is checked after the child finishes; this is not a hard filesystem-write sandbox. Sources and the pinned compiler are trusted build inputs, not arbitrary downloaded executable code. The current source set has two self-contained files; imported shader modules are not an established source-package contract.

Packages are immutable, input-keyed build outputs. Compilation stages privately and publishes only after every entry succeeds; existing nonempty outputs are preserved. CMake hashes sources, compiler-private payloads and validator to choose a new output directory when inputs change. `manifest.json` records tool versions and SHA-256 identities, bundled libraries/modules, source and artifact hashes. Reflection is an offline artifact, not a JSON parser linked into the game. Ten Python public-process tests cover validation, descriptors, compiled CPU layouts/vertex inputs, identity, repeat-cook bytes, size/capability/warning rejection, later-entry failure and preservation of an existing package. Native C++ static assertions establish the supported type layouts.

All four final GPU runs use explicit synchronization validation. `require-sync-validation.cpp` observes the real instance chain and rejects missing enablement. The fixture initially requested ordinary validation only; the real observer Red failed, then opting into Context's existing presentation/validation contract passed. The fixture itself never requests a presented frame. The observer's first setup compile omitted `<cstdint>`; that setup error was corrected and is not counted as a behavioral Red. The earlier runs without this observer are preliminary, not synchronization-validation evidence.

The physical GPU is Iris Xe / Mesa 26.2.6 / Wayland. `shader_gpu_probe` loads actual cooked modules, creates real compute/graphics pipelines and tests:

- Six culling counts (0, 1, 63, 64, 65, 130): 1,152 readback values, tangent/inside/outside spheres on three axes and untouched guards past the requested count.
- Nine 64×64 offscreen draws: non-symmetric/nonuniform matrix coverage across all 4,096 pixels; known linear-HDR PBR samples for sRGB versus UNORM decode, metallic/roughness factors, constant IBL/occlusion, capped local lights, normal maps, emissive contribution, shadow comparison and alpha masking.
- Finite RGB values and alpha coverage. Analytic center-pixel RGB tolerance is 0.004; clear/mask tolerance is 0.00001. Constant one-mip cubemaps/LUT texels isolate interface/math behavior; these are not validated environment-map generation or material-quality assets.

This is a **test-only native fixture**: it uses the existing Context and VMA implementation, owns its own allocations/descriptors/pipelines, waits on finite fences before CPU access/reuse and proves device completion before teardown. It never natively submits a Context-owned `Buffer` or `Image`, so it cannot bypass their last-use registry. It is not a second runtime resource backend. Its controlled idle/wait usage is not a frame-performance design; shipping draws must integrate with tracked retirement separately.

The two ASan/UBSan/leak sensitivity controls remove the culling guard or transpose the model multiplication in temporary shader copies. Both compile/validate but exit 1 for the expected behavioral mismatch, without validation or sanitizer diagnostics. They demonstrate that native checks observe actual GPU outputs, not just successful pipeline creation. `verify-controls.py` retains this reproduction without editing sources.

`artifacts/` contains one actual pinned-tool package and its manifest/reflection. `pbr-linear.pfm` is a bottom-up float RGB readback of the baseline PBR fixture, not scanout. `pbr-srgb.png` is a display-converted review copy made with ImageMagick (`-set colorspace RGB -colorspace sRGB`), not an engine post-processing result. Hashes identify these retained bytes, not reproducible driver binaries or exhaustive secret detection.
