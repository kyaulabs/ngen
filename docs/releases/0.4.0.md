## ✨ Highlights

NGEN 0.4.0 adds bounded cosmetic particles and an opt-in GPU motion-vector
attachment. These are new engine features, so this is a minor bump from 0.3.0.
The default flight preset, authored mesh exhaust and source SDK workflow remain
unchanged. Combined M4-C history verification, warp and streaming are still open.

- The cosmetic pool uses fixed 60 Hz ticks and owning frame-stamped snapshots.
  Its public synthetic rendered fixture retains particle trajectory and occupancy
  across an origin transfer. The accepted flight preset does not emit new particles.
- `flight_demo --motion-vectors` enables a Vulkan attachment for opaque and
  alpha-masked geometry. It stores current-to-previous framebuffer displacement
  and explicit validity. No upscaler, new output file, or transparent/particle/sky
  vectors are included.

## 🛠️ Get started

Download the source tarball and its checksum into a fresh directory:

```sh
sha256sum -c ngen-0.4.0-source.tar.gz.sha256
tar -xzf ngen-0.4.0-source.tar.gz
cd ngen-0.4.0
```

Or clone the tagged source:

```sh
git clone --branch v0.4.0 --depth 1 https://github.com/kyaulabs/ngen.git
cd ngen
```

The primary profile needs Linux x86-64, Clang 23.1.4, Python 3.11+, Conan 2.34.0,
CMake 4.4.5, Ninja 1.13.2, and standard native build tools. The initial dependency
build needs network access; the CPU harness needs no GPU, window, account or service.

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install 'conan==2.34.0' 'cmake==4.4.5' 'ninja==1.13.2'
clang++ --version  # Confirm the primary toolchain version.
sh tools/prepare.sh release
cmake --preset release -DNGEN_INSTALL_SDK=ON
cmake --build --preset release
ctest --preset release --output-on-failure --no-tests=error
./build/release/sim_harness
```

To validate the public particle and motion fixture on a compatible Vulkan desktop
with the Khronos validation layer, build the renderer and run the synthetic probe:

```sh
sh tools/prepare.sh demo-release
cmake --preset demo-release
cmake --build --preset demo-release
./build/demo-release/scene_probe
```

For flight itself, supply an authorized compatible cooked scene. No such private
asset is in this release. Linux desktop audio uses the existing Pulse path.

```sh
./build/demo-release/flight_demo /absolute/path/to/your-scene.ngas --validation --motion-vectors
```

## ✅ Verification

[PR #99](https://github.com/kyaulabs/ngen/pull/99) and
[PR #100](https://github.com/kyaulabs/ngen/pull/100) added these features. Local
Release and strict sanitizer demo suites passed 27/27 each. On Intel Iris Xe with
Vulkan validation, particle and motion readbacks matched their no-transfer controls.
The independent motion check measured a maximum error of 0.00558 px against a
0.25 px fixture limit. The fixture color output was unchanged, and an opt-in flight
replay completed. These are scoped results, not a new performance or Windows GPU
claim. Publication requires exact main CI and verified draft downloads; all
previously published tags and files remain unchanged.
