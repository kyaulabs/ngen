## ✨ Highlights

NGEN 0.17.0 adds a saved Surveyors campaign that runs in a Linux terminal. This minor source release does not change the installed engine SDK.

## 🚀 Features and fixes

Start in protected space, choose the Surveyors' career, and accept the risks of a lawless mining sortie. Win the scripted encounter or recover a starter and salvage the wreck before docking to sell. Credits and ore come from finite balances. Reopening a save reconstructs the same receipts, so retrying a sale does not pay twice.

The optional quest build uses pinned Lua 5.5.1 for one first-party career choice. It does not load outside scripts or bytecode. The quest is headless; it does not add live flight integration, NPC police behavior, multiplayer, or acceptance of the full M5 milestone.

## 🛠️ Get started

```sh
sha256sum -c ngen-0.17.0-source.tar.gz.sha256
tar -xzf ngen-0.17.0-source.tar.gz
cd ngen-0.17.0
```

Prepare the [headless source dependencies](https://github.com/kyaulabs/ngen/blob/v0.17.0/docs/creator-sdk.md). Follow the [Surveyors walkthrough](https://github.com/kyaulabs/ngen/blob/v0.17.0/docs/evidence/M5/saved-survey.md) to opt in to the Lua build and start a local save. Review the [source and dependency notices](https://github.com/kyaulabs/ngen/tree/v0.17.0/licenses) before redistributing.

## ✅ Verification

All 13 opt-in Release CTests passed with the verified Lua source. The four quest CTests passed under ASan/UBSan/LSan with Lua instrumented. The test CLI reopens the save for each step, including loss, recovery, salvage, sale, and a replayed receipt. These checks are not a one-hour live flight run or an owner playthrough.
