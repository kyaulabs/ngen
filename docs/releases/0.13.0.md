## ✨ Highlights

NGEN 0.13.0 adds opt-in creator edits over local MCP. This minor source release does not change the installed engine SDK.

## 🚀 Features and fixes

The companion remains read-only by default. With `--allow-edits`, the client can preview or save a manifest rename, fixed `main.cpp` replacement, or scene entity edit in its one granted starter project. Saves check the expected revision and atomically replace one file. Diffs summarize changes without returning source or asset text.

This grant does not include arbitrary paths, asset writes, builds, playtests or writes to active snapshots. It is intended for a trusted local launcher and stdio peer, not a remote service. See the [creator MCP guide](https://github.com/kyaulabs/ngen/blob/v0.13.0/docs/creator-mcp.md) for the exact limits and launcher commands.

## 📦 Downloads

This release distributes **source and checksums only**. There are no binaries, installers, recordings or private scenes. GitHub's automatic source links are separate from the verified payload.

| File | Purpose |

Checksums verify integrity, not publisher identity. The annotated tag identifies the signed promotion merge and is not independently GPG-signed.

## 🛠️ Get started

```sh
sha256sum -c ngen-0.13.0-source.tar.gz.sha256
tar -xzf ngen-0.13.0-source.tar.gz
cd ngen-0.13.0
```

Follow the [creator MCP guide](https://github.com/kyaulabs/ngen/blob/v0.13.0/docs/creator-mcp.md) for the optional Python environment and the [SDK guide](https://github.com/kyaulabs/ngen/blob/v0.13.0/docs/creator-sdk.md) for headless source builds. First-time dependency preparation can require network access. Review the [source and dependency notices](https://github.com/kyaulabs/ngen/tree/v0.13.0/licenses) before redistributing.
