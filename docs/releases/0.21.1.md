## ✨ Highlights

NGEN 0.21.1 fixes the Linux creator setup instructions. The sample and SDK guides now link to the toolchain setup bundled with their source version, and the guide shows how to verify and select the native Ninja 1.13.2 executable.

## 🚀 Features and fixes

The PyPI Ninja wheel can report a suffixed version that `prepare.sh` rejects. Follow the [Linux toolchain guide](https://github.com/kyaulabs/ngen/blob/v0.21.1/docs/build-toolchain.md) instead. The strict version guard and dependency locks are unchanged.

## 📦 Downloads

This release distributes **source and checksums only**. GitHub's automatic source links are separate from the verified payload.

| File | Purpose |
|---|---|
| `ngen-0.21.1-source.tar.gz` | Versioned source, sample inputs, build files and notices |
| `ngen-0.21.1-source.tar.gz.sha256` | SHA-256 checksum for the source archive |
| `ngen-0.21.1-SHA256SUMS` | Complete release checksum inventory |

Checksums verify integrity, not publisher identity. The annotated tag identifies the signed promotion merge and is not independently GPG-signed.

## 🛠️ Get started

```sh
sha256sum -c ngen-0.21.1-source.tar.gz.sha256
tar -xzf ngen-0.21.1-source.tar.gz
cd ngen-0.21.1
```

Use `docs/build-toolchain.md` first, then `samples/README.md`. Dependency setup may need network access; the samples run offline.
