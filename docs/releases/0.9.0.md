## ✨ Highlights

NGEN 0.9.0 adds an opt-in two-system flight replay. The journey departs a protected starter system and arrives in a lawless system. A destination file is read off the frame thread. The flight loop keeps queuing the proxy while the destination is unavailable, then switches only after the checked GPU upload and collision handoff complete. The replay uses a synthetic landmark; it is not an interactive galaxy or final game art.

The fixture covers missing or corrupt files, one retry and a corrected occupied berth. The normal demo and standalone creator SDK do not require the crossing option or new dependencies.

## 📦 Downloads

This release distributes **source and checksums only**. It contains no private scene packages, binaries, installers or recordings. GitHub's automatic source archives are separate from the checked payload.

## 🛠️ Get started

```sh
sha256sum -c ngen-0.9.0-source.tar.gz.sha256
tar -xzf ngen-0.9.0-source.tar.gz
cd ngen-0.9.0
```

For the headless SDK and dependency setup, follow the [source-built SDK guide](https://github.com/kyaulabs/ngen/blob/v0.9.0/docs/creator-sdk.md). For the bounded crossing commands and tested fixture, see [M4 flight acceptance](https://github.com/kyaulabs/ngen/blob/v0.9.0/docs/evidence/M4/flight-acceptance.md). A local compatible frigate package is required for the graphical replay and is not among the release downloads. Review [source and dependency notices](https://github.com/kyaulabs/ngen/tree/v0.9.0/licenses) before redistributing.

## ✅ Verification

The Iris Xe flight replay ran 600 measured frames after a 60-frame warmup, three times per control, healthy crossing and corrupt-file recovery. The longest observed host queue gap across the crossing runs was 45.186 ms. The separate Vulkan-validation run recovered from an occupied berth and completed with motion vectors enabled. Timing is host queue evidence, not scan-out; tracked resource records, sampled DRM and process high-water RSS are separate views. See the flight acceptance note for the exact revisions, hashes and measurement limits.
