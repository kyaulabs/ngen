## ✨ Highlights

NGEN 0.19.0 brings the saved Surveyors charter into the Linux flight window. This is an opt-in minor source release. The default flight demo, text fixture and installed SDK do not require Lua.

## 🚀 Features and fixes

Fly the existing Jolt contact body into a settled berth, cross to the frontier, and complete the charter through victory or loss and salvage. A new outbound crossing waits for its scene and native berth before saving. Reopening a committed charter restores its system even if the decorative landmark is unavailable. The return sale cannot pay twice on replay.

Mining and combat remain bounded fixture actions rather than aiming or mining a live physics target. This release does not establish one-hour B4 memory or market-latency acceptance, independent gameplay and economy review, or a recorded owner playthrough.

## 🛠️ Get started

```sh
sha256sum -c ngen-0.19.0-source.tar.gz.sha256
tar -xzf ngen-0.19.0-source.tar.gz
cd ngen-0.19.0
```

Prepare the [source dependencies](https://github.com/kyaulabs/ngen/blob/v0.19.0/docs/creator-sdk.md) and the [pinned Lua 5.5.1 package](https://github.com/kyaulabs/ngen/blob/v0.19.0/docs/evidence/M5/saved-survey.md). Build the `demo-release` preset with `NGEN_BUILD_QUEST_SCRIPT=ON`. The [windowed voyage guide](https://github.com/kyaulabs/ngen/blob/v0.19.0/docs/evidence/M5/windowed-voyage.md) explains the separate cooked inputs, charter and validation replay. Review the [source and dependency notices](https://github.com/kyaulabs/ngen/tree/v0.19.0/licenses) before redistributing.
