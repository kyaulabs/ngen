## ✨ Highlights

NGEN 0.10.0 is a minor source release for M5-A: an offline inventory and GameCredit transfer fixture. It changes no installed SDK API.

## 🚀 Features and fixes

A local session can buy and sell one resource. Exact retries return the original receipt or rejection; changed requests cannot reuse an admitted ID. Overflow, insufficient holdings, or a full journal leave the two accounts unchanged. The journal is in-memory; this is not a playable market or durable economy. It adds no database, blockchain, or wallet dependency.

The [roadmap](https://github.com/kyaulabs/ngen/blob/v0.10.0/docs/planning/execution-order.md) records when the separate Space MMO repo starts and adopts multiplayer and persistence. External settlement remains optional and unselected.

## 📦 Downloads

This release distributes **source and checksums only**. It includes no binaries, private scenes, installers, or recordings. GitHub's automatic source archives are separate from the verified payload.

Checksums verify integrity, not publisher identity. The annotated source tag identifies the signed promotion merge and is not separately GPG-signed.

## 🛠️ Get started

```sh
sha256sum -c ngen-0.10.0-source.tar.gz.sha256
tar -xzf ngen-0.10.0-source.tar.gz
cd ngen-0.10.0
```

Follow the [source-built SDK guide](https://github.com/kyaulabs/ngen/blob/v0.10.0/docs/creator-sdk.md) to prepare the headless dependency graph. First-time dependency preparation can require network access. After `cmake --preset release` and `cmake --build --preset release`, run `ctest --preset release -R '^economy$' --output-on-failure --no-tests=error`. That test needs no GPU, server, or private scene. Review the [source and dependency notices](https://github.com/kyaulabs/ngen/tree/v0.10.0/licenses) before redistributing.

## ✅ Verification

The fixture verified credit and inventory conservation in both trade directions, stable successful and rejected retries, identifier conflicts, insufficient holdings, overflow and journal saturation. Linux Clang Release and strict ASan/UBSan/LSan each passed the five headless CTests. See [M5-A evidence](https://github.com/kyaulabs/ngen/blob/v0.10.0/docs/evidence/M5/local-market.md) for the contract and limits. This does not accept M5's integrated offline loop.
