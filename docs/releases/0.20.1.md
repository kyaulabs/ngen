## ✨ Highlights

NGEN 0.20.1 fixes a fresh-build failure in the optional Surveyors recorder. It does not change gameplay, save compatibility, or the recording scope.

## 🚀 Features and fixes

`tools/record_survey.py` now selects Clang for both the generated Wayland C protocol and the C++ Qt helper. The previous launcher could select GCC for C on a clean host, then fail because Qt passed a Clang-specific flag. Cached builds with both Clang compilers installed did not expose the issue.

## 📦 Downloads

This release distributes **source and checksums only**. There are no binaries, installers, recordings or private scenes. GitHub's automatic source links are separate from the verified payload.

| File | Purpose |
|---|---|
| `ngen-0.20.1-source.tar.gz` | Versioned source, build inputs, public fixtures and notices |
| `ngen-0.20.1-source.tar.gz.sha256` | SHA-256 checksum for the source archive |
| `ngen-0.20.1-SHA256SUMS` | Complete release checksum inventory |

Checksums verify integrity, not publisher identity. The annotated tag identifies the signed promotion merge and is not independently GPG-signed.

## 🛠️ Get started

```sh
sha256sum -c ngen-0.20.1-source.tar.gz.sha256
tar -xzf ngen-0.20.1-source.tar.gz
cd ngen-0.20.1
```

Follow the [windowed voyage guide](https://github.com/kyaulabs/ngen/blob/v0.20.1/docs/evidence/M5/windowed-voyage.md) for dependencies and the owner recording command. The recorder captures only the launched game window. No private media is included or uploaded.

## ✅ Verification

The actual v0.20.0 launcher reproduced the C compiler failure from a fresh extraction with no compiler environment overrides. The fix built the helper from a fresh extraction and reached the owned-window admission check. Host-independent recorder policy tests passed. M5 still requires the independent review and the owner's recorded playthrough.
