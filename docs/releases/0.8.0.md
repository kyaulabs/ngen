## ✨ Highlights

NGEN 0.8.0 adds an optional Linux MCP companion over stdio. A local client can read the starter manifest schema and SDK guide, then inspect validated scene and asset metadata for one project selected by the launcher. The engine SDK does not depend on MCP.

The companion cannot edit a scene, run a build, control a playtest, or listen on the network. Those are not part of this release.

## 📦 Downloads

This release distributes **source and checksums only**. It contains no binaries, installers, private scenes, or recordings. GitHub’s automatic source archives are separate from the verified payload.

| File | Purpose |
|---|---|
| `ngen-0.8.0-source.tar.gz` | Versioned source, build inputs, public fixtures and notices |
| `ngen-0.8.0-source.tar.gz.sha256` | SHA-256 checksum for the source archive |
| `ngen-0.8.0-SHA256SUMS` | Complete release checksum inventory |

Checksums verify integrity, not publisher identity. The annotated tag identifies the signed promotion merge and is not separately GPG-signed.

## 🛠️ Get started

```sh
sha256sum -c ngen-0.8.0-source.tar.gz.sha256
tar -xzf ngen-0.8.0-source.tar.gz
cd ngen-0.8.0
```

Follow the [creator MCP guide](https://github.com/kyaulabs/ngen/blob/v0.8.0/docs/creator-mcp.md) to install the optional Python dependency in a virtual environment and launch the companion with one explicit project directory. For engine builds, see the [source-built SDK guide](https://github.com/kyaulabs/ngen/blob/v0.8.0/docs/creator-sdk.md). See [source and dependency notices](https://github.com/kyaulabs/ngen/tree/v0.8.0/licenses) before redistributing.
