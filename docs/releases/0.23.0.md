## ✨ Highlights

NGEN 0.23.0 completes the local creator workflow over MCP stdio. With `--allow-create`, a client can initialize the starter in one launcher-selected empty private directory. Creation does not grant edits, jobs or play.

## 🚀 Features and fixes

The scripted board test creates and edits the project, cooks, builds and tests it in the existing Linux job sandbox, plays and reloads the saved board through its separate runtime, and exports a local source archive. It also checks stale requests, refusal of overlapping jobs and owned cancellation. The [creator MCP guide](https://github.com/kyaulabs/ngen/blob/v0.23.0/docs/creator-mcp.md) describes the grants and host requirements.

## 🛠️ Get started

```sh
sha256sum -c ngen-0.23.0-source.tar.gz.sha256
tar -xzf ngen-0.23.0-source.tar.gz
cd ngen-0.23.0
```

Use `docs/build-toolchain.md` for Linux setup and `docs/creator-mcp.md` for the opt-in companion. Build dependencies may need network setup once; the job and play profiles run offline.
