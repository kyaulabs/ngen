## ✨ Highlights

NGEN 0.15.0 adds M5-E docking-gated market access. This minor source release does not change the installed engine SDK.

## 🚀 Features and fixes

A vessel must complete a scripted berth capture before trading at the station or planetary orbital hub fixture. Abort and departure close market access without replacing the vessel, its cargo or its trade receipts. Re-docking lets the same vessel replay an old receipt without applying the trade twice.

This is one offline scripted berth and its local market, not live flight docking, planetary surface physics, a network authorization system or a persistent economy.

## 🛠️ Get started

```sh
sha256sum -c ngen-0.15.0-source.tar.gz.sha256
tar -xzf ngen-0.15.0-source.tar.gz
cd ngen-0.15.0
```

Use the [SDK build guide](https://github.com/kyaulabs/ngen/blob/v0.15.0/docs/creator-sdk.md) to prepare the source dependencies. Build the Release preset and run `ctest --preset release -R '^docking$' --output-on-failure --no-tests=error`. This fixture does not need a GPU, server or private asset. Review the [source and dependency notices](https://github.com/kyaulabs/ngen/tree/v0.15.0/licenses) before redistributing.
