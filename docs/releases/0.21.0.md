## ✨ Highlights

NGEN 0.21.0 adds two source-built creator SDK samples: a non-space board and a two-tick space docking exercise. Both use the installed SDK, the public starter triangle and existing tools, with no private assets or flagship code.

## 🚀 Features and fixes

Follow one [sample guide](https://github.com/kyaulabs/ngen/blob/v0.21.0/samples/README.md) to create, cook, build, test, run and source-package both projects. Play and reload the saved board layout through the existing owned board session. Neither sample requires a GPU or game server. No SDK ABI or new dependencies are introduced.

## 🛠️ Get started

```sh
sha256sum -c ngen-0.21.0-source.tar.gz.sha256
tar -xzf ngen-0.21.0-source.tar.gz
cd ngen-0.21.0
```

Start with `samples/README.md` and use a fresh local install prefix. Initial toolchain and dependency preparation may require network access.

## ✅ Verification

Release and strict ASan/UBSan/LSan passed all 15 asset SDK CTests on Linux x86-64 with Clang. A fresh source extraction passed the native creator tests without network or display. The samples meet C1-E; independent creator acceptance and independent M5 gameplay/economy review remain separate gates.
