## ✨ Highlights

NGEN 0.22.0 adds separately granted MCP control of one owned headless board playtest. Local clients can start, inspect, reload and stop the session with checked project, session and generation identities.

## 🚀 Features and fixes

The [creator MCP guide](https://github.com/kyaulabs/ngen/blob/v0.22.0/docs/creator-mcp.md#opt-in-board-playtest) explains the `--allow-play` grant and trusted launcher paths. The runtime uses the existing Bubblewrap board profile and does not execute project C++ or CMake code. Edit and job grants do not grant play. The client cannot select an executable, attach to another process, or target live servers or flagship play.

## 🛠️ Get started

```sh
sha256sum -c ngen-0.22.0-source.tar.gz.sha256
tar -xzf ngen-0.22.0-source.tar.gz
cd ngen-0.22.0
```

Use `docs/build-toolchain.md` and `docs/creator-mcp.md` for the Linux toolchain, native board tools and optional local stdio adapter.

All 10 MCP and four owned job tests passed over real stdio.
