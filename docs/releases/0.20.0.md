## ✨ Highlights

NGEN 0.20.0 adds an opt-in Surveyors recording launcher for KDE Wayland. This minor source release also includes the verified B4 soak workload and trace. The installed SDK and default flight controls are unchanged.

## 🚀 Features and fixes

`tools/record_survey.py` launches an interactive charter and records only that window. Play after the readiness message, then close the window to finish a private video. Reopen the same charter to record the reload in a separate clip. The recorder does not pilot the ship, capture system audio or microphone, or upload anything.

The one-hour B4 run passed its declared flight, memory and market budgets. The independent gameplay/economy review and recorded owner playthrough are still required for M5 acceptance.

## 📦 Downloads

This release distributes **source and checksums only**. There are no binaries, installers, recordings or private scenes. GitHub's automatic source links are separate from the verified payload.

| File | Purpose |
|---|---|
| `ngen-0.20.0-source.tar.gz` | Versioned source, build inputs, public fixtures and notices |
| `ngen-0.20.0-source.tar.gz.sha256` | SHA-256 checksum for the source archive |
| `ngen-0.20.0-SHA256SUMS` | Complete release checksum inventory |

Checksums verify integrity, not publisher identity. The annotated tag identifies the signed promotion merge and is not independently GPG-signed.

## 🛠️ Get started

```sh
sha256sum -c ngen-0.20.0-source.tar.gz.sha256
tar -xzf ngen-0.20.0-source.tar.gz
cd ngen-0.20.0
```

Follow the [windowed voyage guide](https://github.com/kyaulabs/ngen/blob/v0.20.0/docs/evidence/M5/windowed-voyage.md) for optional Lua, compatible cooked inputs and the recording command. The [B4 result](https://github.com/kyaulabs/ngen/blob/v0.20.0/docs/evidence/M5/b4-soak-results.md) links the trace and its verifier.

## ✅ Verification

All 11 recorder tests passed on the local KDE Wayland host. The capture completed on window close and at its time limit; the legacy A/V recorder still completed its fixed-duration run and rejected premature close. The B4 run reopened 391 sales and held the market target without counting persistence time. No test clip stands in for the owner's playthrough.
