## ✨ Highlights

NGEN 0.11.0 adds the M5-B offline mining fixture. This minor release changes no installed SDK API.

## 🚀 Features and fixes

A claim moves only the ore available within the requested limit and remaining cargo space. Concurrent claims cannot overdraw an asteroid, and duplicate operation IDs return the first recorded outcome without duplicating cargo. An explicit replenishment command moves ore from a finite reserve instead of creating it.

The fixture covers one asteroid, one cargo hold and one reserve. Receipts are in-memory. This release does not add timed mining, a playable mining loop, network authorization, or durable saves.

## 🛠️ Get started

```sh
sha256sum -c ngen-0.11.0-source.tar.gz.sha256
tar -xzf ngen-0.11.0-source.tar.gz
cd ngen-0.11.0
```

Follow the [source-built SDK guide](https://github.com/kyaulabs/ngen/blob/v0.11.0/docs/creator-sdk.md) to prepare the headless dependency graph. First-time dependency preparation can require network access. Run `cmake --preset release`, `cmake --build --preset release`, and `ctest --preset release -R '^mining$' --output-on-failure --no-tests=error`. The fixture needs no GPU, server, or private scene. Review the [source and dependency notices](https://github.com/kyaulabs/ngen/tree/v0.11.0/licenses) before redistributing.

## ✅ Verification

Linux Clang Release, strict ASan/UBSan/LSan and TSan each passed all six headless CTests. The mining test also passed 20 repeated TSan runs. See [M5-B evidence](https://github.com/kyaulabs/ngen/blob/v0.11.0/docs/evidence/M5/bounded-mining.md) for recorded quantities and limits. This does not accept M5's integrated offline loop.
