## ✨ Highlights

NGEN 0.14.0 adds the M5-D wreck and starter recovery fixture. This minor source release does not change the installed engine SDK.

## 🚀 Features and fixes

A destroyed fixture ship creates one wreck holding its surviving cargo. One recovery entitlement restores an empty starter, without issuing sellable items or credits. Salvage can move existing cargo back to a live ship exactly once. Retries do not duplicate ships, wrecks, or cargo, and a salvage/death race leaves the cargo with one owner.

The fixture is single-pilot and in-memory. It does not introduce persistent wrecks, a sale interface, multiplayer salvage, or live flight integration. The session retains up to 16 losses and rejects further recovery before issuing a ship it cannot track.

## 🛠️ Get started

```sh
sha256sum -c ngen-0.14.0-source.tar.gz.sha256
tar -xzf ngen-0.14.0-source.tar.gz
cd ngen-0.14.0
```

Use the [SDK build guide](https://github.com/kyaulabs/ngen/blob/v0.14.0/docs/creator-sdk.md) to prepare the headless source dependencies. Then build the Release preset and run `ctest --preset release -R '^lifecycle$' --output-on-failure --no-tests=error`. This fixture does not need a GPU, server, or private asset. Review the [source and dependency notices](https://github.com/kyaulabs/ngen/tree/v0.14.0/licenses) before redistributing.
