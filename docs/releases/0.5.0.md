## ✨ Highlights

NGEN 0.5.0 adds local flight and camera history across stationary origin transfers.
Navigation targets remain in their authored frame. The camera aligns each pose
at its own tick before interpolation; incompatible frame stamps are rejected.
Compatible transfers preserve the previous presentation for motion vectors.
Resets replace the authored basis and invalidate that history.

The public demo fixture now compares the production HDR, shadow and motion
attachments alongside a live particle pool. The flight demo does not schedule
origin transfers on its own. Warp, streaming and network prediction are not in
this release. Existing SDK startup, default flight and opt-in motion output remain.

## 🛠️ Get started

From a new directory containing the downloaded source archive and checksum:

```sh
sha256sum -c ngen-0.5.0-source.tar.gz.sha256
tar -xzf ngen-0.5.0-source.tar.gz
cd ngen-0.5.0
```

Or clone the tagged source:

```sh
git clone --branch v0.5.0 --depth 1 https://github.com/kyaulabs/ngen.git
cd ngen
```

The primary profile needs Linux x86-64, Clang 23.1.4, Python 3.11+, Conan 2.34.0,
CMake 4.4.5, Ninja 1.13.2 and standard native build tools. Initial dependency
preparation needs network access. The CPU harness needs no GPU, window or service.

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install 'conan==2.34.0' 'cmake==4.4.5' 'ninja==1.13.2'
clang++ --version
sh tools/prepare.sh release
cmake --preset release -DNGEN_INSTALL_SDK=ON
cmake --build --preset release
ctest --preset release --output-on-failure --no-tests=error
./build/release/sim_harness
```

On a Vulkan desktop with the Khronos validation layer, run the public synthetic
flight-history fixture without a private scene:

```sh
sh tools/prepare.sh demo-release
cmake --preset demo-release
cmake --build --preset demo-release
./build/demo-release/scene_probe
```

For the interactive flight demo, supply your own authorized compatible cooked
scene. Linux desktop audio uses the existing Pulse path.

```sh
./build/demo-release/flight_demo /absolute/path/to/your-scene.ngas --validation --motion-vectors
```

## ✅ Verification

[PR #102](https://github.com/kyaulabs/ngen/pull/102) integrated this work. Release
and strict sanitizer demo graphs passed 27/27 CTests each. The 1920×1080 CPU
control had zero difference in projected position and motion after 120 live
rebases (limit 0.25 px). The validation-enabled Intel Iris Xe fixture produced
byte-identical HDR, 1024×1024 D32 shadows and motion readbacks between fixed and
transferred scenes, with 387 valid motion pixels and three visible particle
pixels. No new performance, Windows GPU or broad M4 acceptance claim.
