## ✨ Highlights

NGEN 0.16.0 adds explicitly granted offline creator jobs for the local MCP companion. This minor source release does not change the installed engine SDK.

## 🚀 Features and fixes

On a supported Linux host, `--allow-jobs` lets the launcher grant fixed cook, build, test, and source-package jobs against one saved project revision. Jobs use bounded systemd scopes and Bubblewrap, and stop and check the owned scope on cancellation. Packaged source stays on the local machine. Discovery stays read-only, and edit permission alone does not grant jobs.

This release does not add a shell tool, dependency downloads, playtest control, public publication, or a fallback for unsupported hosts. See the [creator jobs guide](https://github.com/kyaulabs/ngen/blob/v0.16.0/docs/creator-jobs.md) before granting execution.

## 📦 Downloads

This release distributes **source and checksums only**. There are no binaries, installers, recordings or private scenes. GitHub's automatic source links are separate from the verified payload.

| File | Purpose |
|---|---|
| `ngen-0.16.0-source.tar.gz` | Versioned source, build inputs, public fixtures and notices |
| `ngen-0.16.0-source.tar.gz.sha256` | SHA-256 checksum for the source archive |
| `ngen-0.16.0-SHA256SUMS` | Complete release checksum inventory |

Checksums verify integrity, not publisher identity. The annotated tag identifies the signed promotion merge and is not independently GPG-signed.

## 🛠️ Get started

```sh
sha256sum -c ngen-0.16.0-source.tar.gz.sha256
tar -xzf ngen-0.16.0-source.tar.gz
cd ngen-0.16.0
```

Use the [creator MCP guide](https://github.com/kyaulabs/ngen/blob/v0.16.0/docs/creator-mcp.md) to install the optional companion and the [SDK build guide](https://github.com/kyaulabs/ngen/blob/v0.16.0/docs/creator-sdk.md) for source builds. First-time dependency preparation can require network access. Review the [source and dependency notices](https://github.com/kyaulabs/ngen/tree/v0.16.0/licenses) before redistributing.

## ✅ Verification

Four real stdio job cases passed on the documented local Linux profile. They verified native build/cook/test, source-only packaging, isolation, deadlines, and descendant cleanup. All nine headless CTests and the creator CLI target also passed. See [C2-C evidence](https://github.com/kyaulabs/ngen/blob/v0.16.0/docs/evidence/C2/owned-jobs.md) for the exact environment and limits; this does not complete C2's playtest gate.
