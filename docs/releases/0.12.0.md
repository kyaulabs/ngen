## ✨ Highlights

NGEN 0.12.0 adds the M5-C offline combat fixture. This minor source release changes no installed SDK API.

## 🚀 Features and fixes

The targeted weapon checks range and line of sight. The projectile weapon sweeps its full path so it can hit even when neither endpoint overlaps a target. Both apply damage through one path: the first contact hits the hull or a fitted component at that contact. A disabled mount cannot fire. If the projectile queue is full, new shots are rejected and accepted shots still resolve once, even if a shooter is destroyed.

The fixture uses two stationary ships and optional cover in one local frame. It does not add moving-target collision, multiplayer authority, a playable combat loop or wreck ownership.

## 🛠️ Get started

```sh
sha256sum -c ngen-0.12.0-source.tar.gz.sha256
tar -xzf ngen-0.12.0-source.tar.gz
cd ngen-0.12.0
```

Follow the [source-built SDK guide](https://github.com/kyaulabs/ngen/blob/v0.12.0/docs/creator-sdk.md) to prepare the headless dependency graph. First-time dependency preparation can require network access. Run `cmake --preset release`, `cmake --build --preset release`, and `ctest --preset release -R '^combat$' --output-on-failure --no-tests=error`. The fixture needs no GPU, server, or private scene. Review the [source and dependency notices](https://github.com/kyaulabs/ngen/tree/v0.12.0/licenses) before redistributing.
