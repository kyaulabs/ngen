## ✨ Highlights

NGEN 0.18.0 adds a saved voyage between the protected starter system and lawless frontier. This is a minor source release for a new opt-in Linux fixture. The installed engine SDK and text-only Surveyors save slot are unchanged.

## 🚀 Features and fixes

The `quest_voyage` terminal fixture uses Jolt to cross in both directions. Both legs require checked berth contacts and native arrival before the save can charge the departure fee or publish the return sale. A restart before arrival leaves the source checkpoint. An exact retry after arrival returns the historical receipt without another trip or payment.

The voyage fixture uses fixed headless contacts and trusted first-party Lua 5.5.1. It does not add live controls, scene streaming, multiplayer, or claim full M5 acceptance.

## 🛠️ Get started

```sh
sha256sum -c ngen-0.18.0-source.tar.gz.sha256
tar -xzf ngen-0.18.0-source.tar.gz
cd ngen-0.18.0
```

Prepare the [headless source dependencies](https://github.com/kyaulabs/ngen/blob/v0.18.0/docs/creator-sdk.md) and use the `flight-release` preset with `NGEN_BUILD_QUEST_SCRIPT=ON` and [pinned Lua 5.5.1](https://github.com/kyaulabs/ngen/blob/v0.18.0/docs/evidence/M5/saved-survey.md). Build `quest_voyage` and follow the [saved voyage walkthrough](https://github.com/kyaulabs/ngen/blob/v0.18.0/docs/evidence/M5/saved-voyage.md). Review the [source and dependency notices](https://github.com/kyaulabs/ngen/tree/v0.18.0/licenses) before redistributing.
