# Bounded static glTF import

M2-D starts independently from integrated foundation `e1cc4f4`; shader PR #3 has passed hosted checks but awaits owner Windows/NVIDIA execution. This slice does not depend on adopting that compiler and does not claim to finish cooking, GPU residency or M2.

Implement the offline import boundary first: one embedded glTF 2.0 GLB, static triangle primitives, PBR metallic-roughness materials, UV0/normal/tangent attributes, embedded PNG images, scene/node transforms, `KHR_lights_punctual` and the supplied asset's optional `KHR_materials_emissive_strength`. Preserve source units/coordinates and all declared lights; no silent mesh/light reduction. Reject unsupported required extensions and unsupported features with actionable typed failures. No external buffers, image paths, network URIs, animation, skinning or Draco/meshopt-compressed input are admitted in the first subset. Missing normals/UVs/tangents must be generated correctly where supported or explicitly rejected, never silently invented for the supplied normal-mapped ship.

Use the planned fastgltf importer as an optional tooling-only dependency. The C++ standard library has no glTF parser; the existing runtime dependencies do not provide one. Pin fastgltf 0.9.1 and its actual transitive graph in a separate asset-tool lock, preserving CPU/renderer locks. Reuse its simdjson 4.6.4 dependency explicitly for a bounded metadata preflight: reject duplicate keys, excessive depth/value/object counts, all resource URIs and unsupported declared extensions before the importer parses or copies binary data. Use libpng 1.6.59 for bounded, CRC-checked PNG decoding without color-management transforms: glTF texture slots, not PNG gamma metadata, determine channel interpretation. The standard library and fastgltf do not decode images. KTX remains deferred until texture cooking is implemented.

The first unchanged-frigate import reproduced 106 zero-length tangents and 243 tangents outside the orthogonality tolerance, with otherwise unit normals. The owner explicitly selected **rebuild tangents during cooking**, retaining the original source. Add optional MikkTSpace rebuilding and meshoptimizer 1.0 exact vertex remapping to preserve per-corner tangent discontinuities without arbitrary geometry loss. Strict inspection remains available as a genuine reproducer; the cooking path explicitly opts into rebuilding and reports invalid/missing source tangents, degenerate UV triangles and rebuilt corners. Validate the generated basis rather than loosening its checks. Positions, normals, UVs, triangle count and source bytes remain unchanged; visual normal-map acceptance is still required.

The public importer borrows input bytes only during the call and returns owning values. Admit at most 256 MiB source bytes, bounded primitives/vertices/indices/nodes/materials/images/lights and bounded image dimensions/decoded sizes. Validate accessor ranges/strides/counts, indices, finite attributes/materials/transforms/lights, scene hierarchy and decoded image data before downstream use. Cancellation is cooperative before/after parsing and during extraction; parser, individual image-decoder and MikkTSpace calls themselves are not interruptible. These are admission bounds, not a hard process-memory limit or a sandbox. No importer or external-file access belongs in simulation or runtime loading.

Develop one observable behavior at a time through Catch2/CTest: a small real GLB fixture and exact imported values, malformed ranges/indices/values, unsupported/oversized/missing image data, cyclic graphs, URI rejection and cancellation. Then inspect the actual unchanged frigate in a separate command, retaining its source SHA, geometry/material/image/light counts and bounds. Synthetic fixture data can be committed; the owner's source and generated packages stay in their original ignored locations, with no new distribution-rights claim.

Verify Clang Debug/Release/ASan and GCC native graphs, strict affected consumers, pinned formatting and link isolation. Run a bounded malformed-input corpus under sanitizers and retain real failures/fixes. Review, sign and publish the scoped work. Implemented evidence is retained in [asset-import](../evidence/M2/asset-import/README.md). A malformed-input corpus exposed a collapsed referenced-geometry domain reaching MikkTSpace's spatial hash; admission now measures referenced vertices, not unused source bounds. Full sanitized frigate execution then exposed a 32-bit shift-by-32 in both reference quicksort seed rotations. A public synthetic grid reproduces it. The namespaced [MikkTSpace recipe](../../recipes/mikktspace/README.md) masks only the zero-rotation shift; it does not suppress diagnostics or mutate stock cached sources. All four Linux configurations pass six tests and identical full-frigate inspection summaries. Windows execution and visual normal-map acceptance remain pending.

The next M2-D slice compiles optimized meshes and explicitly chosen KTX2 textures into a versioned checked runtime scene package; runtime loading must work without glTF/importer/network access. Resource publication, version pins and last-use retirement remain separate integration work, not promises made by this importer.
